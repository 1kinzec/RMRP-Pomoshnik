## RMRP Помощник 2.2.0 — полный выпуск

**Установка:** скачайте `RMRP-Pomoshnik-Setup-2.2.0.exe`, запустите и следуйте мастеру. Дальше приложение обновляется само.

- Установщик: ярлык на рабочем столе по желанию, автозапуск с Windows (по умолчанию выключен), автоматическое закрытие старой версии при обновлении, новая версия запускается сразу после тихой установки.
- Автообновление: проверка при запуске и раз в 6 часов, список изменений, проверка SHA-256.
- Законы, поиск по статьям, ИИ-помощник на цитатах из базы, тесты, оверлей (F10), Discord Rich Presence, админ-панель.
- Исправлены «полоски» вместо карточек.

Windows может показать предупреждение SmartScreen: установщик не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

# RMRP Помощник 3.0.0 — Midnight Blue Redesign

## Обновлённый интерфейс
- Главная страница переработана: приветственный баннер с ночным городом, четыре быстрых раздела, персональные показатели, последние изученные статьи и объявления.
- Баннер главной страницы рисуется средствами Tkinter и не требует загрузки изображений из интернета.
- Новая палитра Midnight Navy + Electric Blue во всех разделах приложения.
- Увеличено основное окно и минимальный размер для комфортной работы с контентом.
- Расширена боковая панель, увеличены зоны навигации и отступы.
- Обновлены типографика главного окна и визуальная иерархия.
- Установщик синхронизирован с версией 3.0.0.

## Сохранённые возможности
- Supabase Auth, профили и роли с RLS.
- Законодательство, поиск и синхронизация источников RMRP.
- ИИ-помощник, тесты, памятки, избранное и история.
- Административная панель, игровой оверлей F10 и Discord Rich Presence.
- Автообновление через GitHub Releases с проверкой SHA-256.

## Важно
- Существующие SQL-миграции не изменялись.
- Перед публикацией проверьте GitHub Actions и установку на Windows 11.

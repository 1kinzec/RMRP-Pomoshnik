# 🛡️ RMRP Помощник 2.0

**Законодательство, обучение, тесты и управление для RMRP.** by Kinzec X WOLF

## Что нового в 2.0

- Новый интерфейс по макету: боковая навигация, главная с плитками, «Последнее изученное», объявления.
- **Законы:** карточки с числом глав и статей, просмотр закона с главами, вкладки «Содержание / О законе / Версии», подсветка найденных слов, копирование и избранное.
- **Поиск** по номеру («статья 12», «УК 228»), названию и тексту — с морфологией и ранжированием, история запросов.
- **Нейросеть (ИИ)** — чат, отвечающий цитатами из базы с источником и кнопкой «Открыть статью». Не выдумывает: если материала нет — так и говорит.
- **Тесты:** вкладки «Все / Пройденные / Избранные», сложность звёздами, прохождение в окне, разбор ответов.
- **Админ-панель:** пользователи со статусом Online, роли, жалобы, тесты, законы, объявления, журнал, скример (только Основатель, только с согласия получателя).
- **Discord Rich Presence** (окно настройки как на макете, живой предпросмотр).
- **Оверлей в игре** по F10: быстрые разделы и мгновенный поиск по статьям.
- **Гостевой режим**, вход по логину или email, «Запомнить меня», восстановление пароля.
- Профиль со статистикой, страница «История» (статьи, поиск, вопросы ИИ, тесты).
- Надёжность: фоновые запросы (интерфейс не «замирает»), автообновление токена, постраничная загрузка (>1000 строк), безопасная синхронизация законов (сначала апсерт, потом удаление устаревшего — закон не остаётся пустым при сбое).

## Установка базы (Supabase → SQL Editor, по порядку)

1. `rmrp_database.sql`
2. `release_migration.sql`
3. **`migration_v2.sql`** ← новое
4. `RMRP_PRANKS_AND_PROFILE.sql` (если ещё не выполняли)
5. `RMRP_LAWS_SYNC.sql`
6. `FOUNDER_SETUP.sql` — заменить `EMAIL_ОСНОВАТЕЛЯ` на ваш email

Затем в приложении: **Админ-панель → Законодательство → Синхронизировать RMRP** (загрузит статьи вместе с главами). Другие законы добавляются кнопкой «Добавить закон» со ссылкой на тему форума — они синхронизируются вместе с остальными.

## Discord Rich Presence

1. https://discord.com/developers/applications → New Application → «RMRP Помощник».
2. Скопируйте **Application ID**. Картинку с ключом `rmrp` загрузите в Rich Presence → Art Assets.
3. Основатель вставляет ID один раз в *Настройки → Для Основателя* — он применится у всех. Либо каждый пользователь вводит его в окне Discord.

## Оверлей

Горячая клавиша по умолчанию **F10** (меняется в настройках). Работает поверх игры в оконном и безрамочном режимах; в «настоящем» полноэкранном режиме Windows не позволяет показывать чужие окна.

## Автообновление

Работает через GitHub Releases (репозиторий должен быть **публичным**). Каждая сборка в GitHub Actions публикует релиз `vX.Y.Z` с установщиком и файлом SHA-256; адрес репозитория подставляется в приложение автоматически.
Приложение проверяет релизы при запуске и раз в 6 часов; обновление скачивается, проверяется по SHA-256 и ставится тихо (Windows запросит подтверждение UAC).

**Как выпустить обновление:** поменять версию в `app/rmrp/version.py`, дописать `RELEASE_NOTES.md`, запустить workflow. Первую версию с автообновлением нужно поставить вручную один раз.

## Сборка

GitHub → Actions → **Build and Release RMRP Помощник** → Run workflow (или `git tag v2.2.0 && git push --tags` — версия тега должна совпадать с `app/rmrp/version.py`). Сначала выполняются тесты (парсер, поиск, Discord IPC, дымовой тест интерфейса), затем собираются EXE и установщик.

Локальные тесты: `python3 -I -m unittest discover -s tests` и `python3 -I tests/smoke_gui.py`.

## Безопасность

Publishable key в клиенте — намеренно. **Secret/service_role ключ в приложение добавлять нельзя.** Ограничения доступа обеспечивает RLS Supabase.
Функция `login_email` (вход по логину) возвращает email по логину; если это нежелательно — удалите её из `migration_v2.sql`, вход останется по email.

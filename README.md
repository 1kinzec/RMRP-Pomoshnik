## Release 1.2.0

В релизе:
- авторизация и регистрация через Supabase;
- полностью обновлённый тёмный Legal Tech интерфейс;
- hover/press-анимации и анимированный акцентный индикатор;
- приятные системные звуки кликов, открытия, успеха и ошибки на Windows;
- роли: 👑 Основатель, 🛡️ Администратор, 🔨 Модератор, ⭐ Премиум пользователь, 👤 Пользователь;
- отдельная панель администрирования для ADMIN/FOUNDER;
- управление пользователями, ролями, статусами, Premium и разрешением на розыгрыши;
- законодательство и статьи;
- поиск по статьям;
- избранное;
- тестирование с сохранением результатов;
- история результатов;
- жалобы и модерация;
- объявления;
- журнал действий;
- настройки профиля;
- база-ориентированный помощник без выдумывания ответов;
- автоматическая сборка Windows EXE + Inno Setup через GitHub Actions.

## Важно перед релизом

1. В Supabase должен быть выполнен основной `rmrp_database.sql`.
2. Затем выполнить `release_migration.sql`.
3. Один раз выполнить `FOUNDER_SETUP.sql`, заменив `EMAIL_ОСНОВАТЕЛЯ` на email аккаунта Kinzec.
4. После этого запустить GitHub Actions workflow `Build RMRP Помощник for Windows`.

## Безопасность

Publishable key находится в клиенте намеренно. **Secret key Supabase в приложение добавлять нельзя.** Основные ограничения доступа должны обеспечиваться RLS Supabase.
